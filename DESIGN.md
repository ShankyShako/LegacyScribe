# DESIGN.md

Design decisions that are expensive to reverse. Each entry is dated; later entries may supersede earlier ones and must say so. `CLAUDE.md` keeps the one-line decision table; this file holds the specs workers build from.

## Notes speaker labels (2026-10-16)

**Decision.** Diarize every chunk as it is transcribed (the audio is gone afterwards; Cohere has no timestamps), transcribe each speaker turn separately, and keep one running centroid per speaker for the session so numbers hold across chunks. The user's voice is a stored voiceprint (WeSpeaker v2, 256-d, enrolled from History recordings on request) that seeds the registry as a fixed speaker "You"; everyone else is "Speaker 2, 3…" in order of first appearance. Storage carries voiceprint IDs so named voiceprints ("Speaker 2 = Priya") can come later without a format change; the first build creates only `you`. Labels are rendered only when a session heard more than one speaker, so a solo ramble reads exactly as today.

Consistent with: "Notes keep no audio" (nothing new is kept), "Notes use their own CohereClient" (the diarizer is another per-session model next to the VAD), "Notes speech gate" (Silero stays the gate, per turn), "Voiceprint" (own stored item, deleted only on explicit request, not touched by coach deletion), Private mode (model download blocked → unlabelled fallback, never a failure).

2. **`HexCore/Sources/HexCore/Notes/SpeakerRegistry.swift`** (new, pure).
   `public struct SpeakerRegistry: Codable, Equatable, Sendable { public struct Speaker: Codable, Equatable, Sendable { id: Int; name: String?; voiceprintID: String?; fixed: Bool; embedding: [Float]; seconds: Double; turns: Int } ; public private(set) var speakers: [Speaker] }`.

The threshold constants are `public static let`.
   `func label(_ id: Int) -> String`: `name ?? "Speaker \(id)"`. `var speakerCount: Int` counts speakers with `turns > 0`.

### Risks

- The `0.5` same-speaker threshold is unmeasured; if the Q&A run (11b) yields more than 8 speakers, raise it, and if two voices merge, lower it. A mixed cluster (user over someone else) scored 0.45 and will be labelled "You"; if that shows in use, raise `matchThreshold` to 0.5 (the user's own cluster was 0.61). Both are one-line constants.
- One Cohere call per turn instead of per chunk: more calls on a busy chunk. Diarization is ~0.1 s per chunk (4 s per 18 min); watch the `pending/` backlog in the Q&A run; if it grows, cap turns per chunk at 8 by merging the shortest.

## Notes trimming (2026-10-16)

**Decision.** Trims are a separate, reversible layer over the transcript: `trims.json` in the session folder holds left-out stretches in sentence coordinates (chunk, turn, sentence); `transcript.jsonl` is never changed by a trim, and the notes, Copy and Export are produced from the transcript with those sentences removed. Sentence splitting is a hand-written deterministic rule in HexCore (no NLTokenizer: stored coordinates must mean the same thing after an OS update). Timeline positions are estimates: each chunk's length in seconds is now stored on its transcript line at commit, and a chunk's sentences are spread over it in proportion to their word counts. Notes are rewritten only on "Write notes again"; stale = the trims' version differs from the version the notes were written from. Saving an Edit re-anchors each trim by the text of its first and last sentence and drops the ones it can't find.

Consistent with: "Notes keep no audio" (nothing new kept; a lost `trims.json` loses only trims), crash-safe commits (`trims.json` is atomic and separate), editable transcripts (Edit shows the full text, `transcript.original.jsonl` unchanged), speaker labels and naming (a trim is sentence-level inside turns; chips, popover and `speakers.json` untouched). Supersedes nothing. The user's choices from `/tmp/trim-mock/A.png` and `B.png`: both selectors share one selection; left-out stretches collapse to a dashed row; no model-suggested tangents.

### Spec

1. **`HexCore/Sources/HexCore/Notes/NotesSentences.swift`** (new, pure). `public enum NotesSentences { public static func split(_ text: String) -> [String] }`: a sentence ends at a run of `.` `?` `!` (optionally followed by a closing `"`, `'` or `)`) that is followed by whitespace; the remainder is the last sentence; each is whitespace-trimmed, empties dropped, empty text → `[]`. "e.g." and "Dr." split too: a finer snap point, not a wrong trim; don't special-case. Done: `NotesSentencesTests`: `"a. b? c!"` → 3; `"3.5 percent is fine."` → 1; `"Yes.\"  Then no"` → 2; text without punctuation → 1; `""` → `[]`.

2. **`NotesTranscriptLine.seconds: Double?`** (`NotesTranscript.swift`): the chunk's length, set by `NotesEngine.transcribe` from `samples.count / NotesChunker.sampleRate` (nil when the file couldn't be read). Encoded only when set; every existing file parses with nil; `edited` carries a line's `seconds` to the paragraph that takes its chunk number (extra paragraphs nil). Done: round trip in `NotesTranscriptTests`; old fixture line → nil.

3. **`HexCore/Sources/HexCore/Notes/NotesTrims.swift`** (new, pure).
   `public struct NotesTrimPoint: Codable, Equatable, Comparable, Hashable, Sendable { chunk: Int; turn: Int /* 0 for an unlabelled line or a gap */; sentence: Int }` ordered lexicographically.
   `public struct NotesTrim: Codable, Equatable, Sendable { start: NotesTrimPoint; end: NotesTrimPoint /* inclusive */; first: String; last: String /* the two sentence texts, for re-anchoring */ }`.
   `public struct NotesTrims: Codable, Equatable, Sendable { public private(set) var version: Int /* 0 = never trimmed */; public private(set) var trims: [NotesTrim] /* sorted, disjoint */ }`, `init()` empty.
   `public struct NotesSentence: Equatable, Sendable { point: NotesTrimPoint; text: String; speaker: Int?; isGap: Bool; wordCount: Int }` and `static func sentences(of: NotesTranscript) -> [NotesSentence]` in transcript order: a gap line is one sentence (`text = gapMarker`, `isGap`, counts as 10 words for the timeline); each turn's sentences from `NotesSentences.split`; a line without turns is turn 0.
   `mutating func leaveOut(from: NotesTrimPoint, to: NotesTrimPoint, in: NotesTranscript)`: orders the two, fills `first`/`last`, merges with every trim it overlaps or touches, `version += 1`.
   `mutating func bringBack(at index: Int)`: removes, `version += 1`.
   `func trimIndex(containing: NotesTrimPoint) -> Int?`.
   `func applied(to: NotesTranscript) -> [NotesTranscriptLine]`: each line with its left-out sentences removed; a turn's text = kept sentences joined by one space; a turn with nothing kept is dropped; an unlabelled line with nothing kept is dropped; a gap inside a trim is dropped; chunk numbers, `seconds`, `overlapping` kept. With no trims, returns `lines` unchanged.
   `func reanchored(to: NotesTranscript) -> NotesTrims`: for each trim, the first sentence in order whose text equals `first`, then the first one at or after it equal to `last`; both found → new points, else the trim is dropped; `version` bumped once if anything changed.
   `static func gist(of: NotesTrim, in sentences: [NotesSentence]) -> String`: the first 8 words of the trim's first sentence, "…" appended when cut.
   Done: `NotesTrimsTests`: leaveOut from mid-turn to mid-turn across two speakers → `applied` gives the kept head and tail as the two turns' texts; a second leaveOut overlapping the first → one trim, version 2; bringBack → empty, version 3; a covered gap and an emptied turn disappear from `applied`; reanchored after a paragraph is inserted before the trim keeps it with shifted coordinates; after the trim's first sentence is edited it is dropped; no trims → `applied` returns the same lines; sorted-keys encode/decode round trip.

4. **`HexCore/Sources/HexCore/Notes/NotesTimeline.swift`** (new, pure). `public struct NotesTimelineSentence: Equatable, Sendable { point; speaker: Int?; start: Double; end: Double; trimIndex: Int? }`. `static func build(_ transcript: NotesTranscript, trims: NotesTrims, sessionSeconds: Double?) -> [NotesTimelineSentence]`: chunk length = `line.seconds`; lines without one share `(sessionSeconds − sum of known) / count of unknown`, at least 1 s each; nil `sessionSeconds` → 25 s each. Chunk start = sum of earlier chunks. Within a chunk, sentence spans are proportional to `wordCount` (zero total → even). `static func nearestStart(to seconds: Double, in:) -> NotesTrimPoint?` (the sentence whose `start` is nearest) and `nearestEnd` (nearest `end`), for the handles. `static func clock(_ seconds: Double) -> String` → "m:ss" or "h:mm:ss". Done: `NotesTimelineTests`: chunks 25 / nil / 25 with session 80 → the middle is 30 and the last ends at 80; spans proportional to words; `nearestStart(27)` snaps to the sentence starting at 25; clock formats.
   Stated accuracy: silence inside a chunk is spread over its words, so a boundary can be off by up to that chunk's silent seconds (≤ ~20 s, usually a few). The strip's caption says "about".

5. **`NotesSessionFolder`**: `trimsURL` (`trims.json`), `loadTrims() -> NotesTrims` (missing or unparsable → `NotesTrims()`), `saveTrims(_:)` atomic with sorted keys; `delete` removes it with the folder as today. **`NotesSession.notesTrimsVersion: Int?`**: the trims version `notes.md` was written from (nil reads as 0). ## Live caption (2026-10-17)

**Decision.** The caption is a second consumer of the existing capture tap, not a second microphone: `SuperFastCaptureController` hands each dictation's 16 kHz samples (pre-roll first) to one `AsyncStream`, and a per-dictation `LiveCaptionClient` feeds them to its own `SpeechAnalyzer` (`.volatileResults + .fastResults`) and emits display updates. Everything that decides what the caption says (finalized/volatile merge, which word is dim, the tail cap) is a pure `LiveCaption` value in HexCore with tests; the app only wires audio in and text out. The caption lives in the existing `InvisibleWindow` (so it follows the pointer's screen like the indicator), starts only after `.microphoneReady` (the mic-start latency stays untouched) and is cancelled at key-up before transcription begins, so it can never sit on the key-up→paste path. The Legacy peek stays as it is (bench: streaming flashes "Legacy" later than the peek). Notes sessions get no caption (their audio goes through `NotesCaptureController`, a different engine). Private mode allows it: SpeechAnalyzer is on-device and `isInstalled` reads installed locales only; nothing is downloaded by the caption. Visuals as approved (`/tmp/caption-mock/options.png` A, `/tmp/caption-pos/positions.png`, `settings.png`; code in the `main.swift` beside each).

Consistent with: "Models load after the microphone is on", "No cancelling by a stray press; Esc has Undo" (Esc cancels the caption with the dictation), Private mode (zero sockets; `PrivateModeTests` must stay green with the caption on), "Spoken instructions" (the peek is untouched), logging rules (caption text is `privacy: .private`).

### Spec

1. **`HexCore/Sources/HexCore/Caption/LiveCaption.swift`** (new, pure).
   `public struct CaptionResult: Equatable, Sendable { isFinal: Bool; text: String; start: Double; end: Double /* seconds of audio */ }`.
   `public struct CaptionText: Equatable, Sendable { words: [String]; dimLast: Bool }` with `var text: String` (words joined by one space) and `var isEmpty`.
   `public struct LiveCaption: Equatable, Sendable { init(); mutating func apply(_ result: CaptionResult); var display: CaptionText }`. Rules (the bench's replay, `LiveStreamBench.swift` lines 110–135): a final result appends its trimmed text to `finalized` and clears the volatile result when `volatile.start < final.end − 0.01`; a volatile result replaces the previous volatile; `display.words` = finalized words + volatile words, kept to the last `LiveCaption.tailWords = 80` (the view truncates at the head anyway; this caps layout cost on a 2-min dictation); `dimLast` is true iff the volatile text has at least one word (the dim word is the last volatile word; a display of finalized text only is all solid). Whitespace-only texts count as empty.
   Done: `LiveCaptionTests`: final "Can you" + volatile "move the" → words 4, dimLast; a later volatile "move the poster" replaces it; a final covering the volatile's range clears it (dimLast false); a final that ends before the volatile starts keeps it; 100 finalized words → 80 shown, the last ones; empty volatile → no dim.

2. **`HexCore/Sources/HexCore/Caption/CaptionPlacement.swift`** (new, pure).
   `public enum CaptionPlacement: String, Codable, CaseIterable, Sendable { case underIndicator, bottom, custom }` (`displayName`: "Under the indicator", "Bottom of the screen", "Where I put it").
   `public struct CaptionSpot: Codable, Equatable, Sendable { x: Double; y: Double }`: the caption's centre as fractions (0–1) of the screen's *visible* frame, top-left origin. Fractions, not points, so the spot survives a resolution change and transfers to another screen.

### Risks

- Two Apple analyzers in the first 3.3 s (peek + caption) are unmeasured together. If item 9's CPU or first-word numbers fail only when `superEarlyDetection` is on, run the peek on the caption's own text instead (a `SuperTrigger.earlyVerdict` on each `CaptionText`) and accept the later flash the bench measured; that is a change to item 6 only.
- `AsyncStream` with `.unbounded` buffering holds samples until the consumer attaches (~tens of ms after `.microphoneReady`); harmless, but if the effect never starts (setting off, model missing) `beginRecording` still created the stream, and the buffered samples live until `finishRecording`: 64 KB per second of dictation, bounded by the 2 h cap. If that reads as waste, create the stream lazily in `recordingSamples()` and feed `recordingHead` first instead.
