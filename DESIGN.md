# DESIGN.md

Design decisions that are expensive to reverse. Each entry is dated; later entries may supersede earlier ones and must say so. `CLAUDE.md` keeps the one-line decision table; this file holds the specs workers build from.

## Notes speaker labels (2026-10-16)

**Decision.** Diarize every chunk as it is transcribed (the audio is gone afterwards; Cohere has no timestamps), transcribe each speaker turn separately, and keep one running centroid per speaker for the session so numbers hold across chunks. The user's voice is a stored voiceprint (WeSpeaker v2, 256-d, enrolled from History recordings on request) that seeds the registry as a fixed speaker "You"; everyone else is "Speaker 2, 3…" in order of first appearance. Storage carries voiceprint IDs so named voiceprints ("Speaker 2 = Priya") can come later without a format change; the first build creates only `you`. Labels are rendered only when a session heard more than one speaker, so a solo ramble reads exactly as today.

Consistent with: "Notes keep no audio" (nothing new is kept), "Notes use their own CohereClient" (the diarizer is another per-session model next to the VAD), "Notes speech gate" (Silero stays the gate, per turn), "Voiceprint" (own stored item, deleted only on explicit request, not touched by coach deletion), Private mode (model download blocked → unlabelled fallback, never a failure).

### Spec

1. **`HexCore/Sources/HexCore/Voice/Voiceprint.swift`** (new, pure).
   `public struct Voiceprint: Codable, Equatable, Sendable { id: String; name: String?; isUser: Bool; embedder: String /* "wespeaker-v2" */; embedding: [Float] /* unit length */; enrolledAt: Date; sourceCount: Int; sourceSeconds: Double; selfScoreMedian: Float }`.
   `public static let userID = "you"`, `public static let matchThreshold: Float = 0.4` (bench: user cluster 0.61, remote voices ≤ 0.24), `public static func cosine(_:_:) -> Float`, `public static func normalizedMean(_ embeddings: [[Float]]) -> [Float]` (moved from lsbench's `VoiceBench.swift`, which then calls HexCore's).
   `public struct VoiceprintStore: Sendable { init(directory: URL); func load(_ id: String) -> Voiceprint?; func all() -> [Voiceprint]; func save(_:) throws /* atomic */; func delete(_ id: String) throws }` over `<data root>/Voiceprints/<id>.json`. `load` returns nil (not a crash) for a file whose `embedder` isn't `"wespeaker-v2"` or whose embedding isn't 256 long. Done: `VoiceprintStoreTests` cover save/load/delete and the two rejections in a temp directory.

2. **`HexCore/Sources/HexCore/Notes/SpeakerRegistry.swift`** (new, pure).
   `public struct SpeakerRegistry: Codable, Equatable, Sendable { public struct Speaker: Codable, Equatable, Sendable { id: Int; name: String?; voiceprintID: String?; fixed: Bool; embedding: [Float]; seconds: Double; turns: Int } ; public private(set) var speakers: [Speaker] }`.
   `init(voiceprints: [Voiceprint])`: one fixed speaker per voiceprint, ids 1…n in the given order (the user's first), `name = voiceprint.isUser ? "You" : voiceprint.name`.
   `mutating func assign(_ embedding: [Float], seconds: Double) -> Int`: normalize; score against every speaker; the best fixed speaker wins if its score ≥ `Voiceprint.matchThreshold` (fixed centroids never move); else the best non-fixed speaker wins if ≥ `sameSpeakerThreshold` (`0.5`, a constant to tune) and its centroid becomes the seconds-weighted normalized mean; else a new speaker with the next id. The threshold constants are `public static let`.
   `func label(_ id: Int) -> String`: `name ?? "Speaker \(id)"`. `var speakerCount: Int` counts speakers with `turns > 0`.
   Done: `SpeakerRegistryTests` with synthetic unit vectors: 0.61 vs the user → 1; 0.24 → new speaker 2; a later vector at 0.9 vs speaker 2 → 2 and the centroid moves but stays unit length (±1e-4); the user's centroid is byte-identical after any number of assigns; a vector at 0.45 vs the user and 0.3 vs others → 1 (documents the cutoff); encode/decode round trip.

3. **`HexCore/Sources/HexCore/Notes/NotesTurns.swift`** (new, pure).
   `public struct SpeakerSegment: Equatable, Sendable { localSpeaker: String; range: Range<Int>; embedding: [Float] }` and `public struct NotesTurn: Equatable, Sendable { localSpeaker: String; range: Range<Int> /* samples */; speech: [Range<Int>]; embedding: [Float] }`.
   `public static func turns(from segments: [SpeakerSegment], speech: [Range<Int>], sampleRate: Int = 16_000) -> [NotesTurn]`: sort by start; join consecutive segments of one local speaker with gaps < 1 s, a turn never longer than 30 s; embedding = normalized mean of its segments; `speech` = the Silero ranges clipped to the turn; a turn shorter than 1 s joins its previous turn (or the next if it is first) and takes that turn's speaker; a turn whose clipped speech totals under `NotesSpeech.minimumSpeechSeconds` is dropped. Audio for Cohere is `NotesSpeech.joined(samples, ranges: turn.speech)`.
   Done: `NotesTurnsTests` cover each rule with hand-built segments.

4. **`NotesTranscriptLine` gains turns** (`NotesTranscript.swift`).
   `public struct NotesTranscriptTurn: Codable, Equatable, Sendable { speaker: Int; text: String }`; `public var turns: [NotesTranscriptTurn]?`; `public init(chunk: Int, turns: [NotesTranscriptTurn])` sets `text` to the turn texts joined by one space (invariant: `text` is always the plain chunk text, so `heardNothing`, `looksLooped`, `wordCount` and `NotesPrompts.pieces` are untouched, and an older app reads the new file). A line without `turns` is one unlabelled chunk, so every existing `transcript.jsonl` parses unchanged.
   `text(of:)` and `paragraphs` take `labels: (Int) -> String?` (default `{ _ in nil }`): with a label function, each turn is its own paragraph/line as `"<label>: <text>"`; without, as today. `NotesEngine` passes labels only when `registry.speakerCount > 1`.
   `edited(_:)`: a paragraph starting with `^(You|Speaker \d+|[^:\n]{1,40}): ` that matches a label in the session's registry becomes a line with one turn of that speaker; other paragraphs stay unlabelled lines; numbering as today.
   Done: `NotesTranscriptTests`: old fixture line parses with `turns == nil`; a turns line encodes `text` and `turns` with sorted keys; `paragraphs` → `edited` round-trips a two-speaker transcript; one-speaker output has no labels.

5. **`session.json`**: no change. **`speakers.json`** (new, `NotesSessionFolder.speakersURL`) holds the encoded `SpeakerRegistry`, written atomically after every chunk whose registry changed, before the transcript commit (a registry ahead of the transcript is harmless; the reverse would renumber). `resumeUnfinished` loads it; missing → a fresh registry seeded from the stored voiceprints (later chunks may then add numbers, acceptable). `delete` removes it with the folder.

6. **`Hex/Clients/NotesSpeakerSplitter.swift`** (new, actor, mirrors `NotesVoiceDetector`): wraps FluidAudio `DiarizerManager`, models via `DiarizerModels.download(to: URL.hexParakeetModelsDirectory.appendingPathComponent("speaker-diarization"))` (the path `lsbench voice` already uses), 5-min retry after a failed load. `func segments(in samples: [Float]) throws -> [SpeakerSegment]` runs `performCompleteDiarization(samples, sampleRate: 16_000)` and normalizes each segment embedding (they aren't unit length). `func embed(_ samples: [Float]) throws -> [Float]`: normalized mean of `extractSpeakerEmbedding` over 10 s pieces (tails under 1 s dropped), for enrolment.

7. **`NotesEngine.transcribe`** (`NotesClient.swift`), when `hexSettings.notesSpeakerLabels` is on: after the Silero gate says there is speech, call the splitter; on any error log once per session and fall back to today's single-line path. Otherwise: `NotesTurns.turns(...)`; for each turn `registry.assign(turn.embedding, seconds:)`, write the turn's joined speech to a temp WAV, `cohere.transcribe` with the same two-attempt retry (a turn failing twice makes the whole chunk a gap, as today); drop a turn whose text is empty or `looksLooped`; the line is `NotesTranscriptLine(chunk:turns:)` (an empty turn list → text ""). Save `speakers.json`, then commit. `prepare()` the splitter alongside the VAD at `start`. The registry is seeded from `VoiceprintStore(directory: <data root>/Voiceprints).all()` with the `isUser` one first.
   `writeNotes`: pass labels into `NotesTranscript.text(of:)` when `speakerCount > 1`, and `NotesPrompts.rules` gets one sentence: `Lines starting with "You:" are the person who recorded; "Speaker N:" are others. Attribute an action item or decision to its speaker when it matters.`
   `NotesContent` gains `speakerCount: Int`; `NotesSessionSummary` too (header shows "· 3 speakers" when > 1).

8. **Enrolment, `Hex/Clients/VoiceprintEnroller.swift`** (new): `func enrolUser(history: [Transcript]) async throws -> Voiceprint`. Sources: `failure == nil`, `audioRemoved != true`, file exists, `duration ≥ 3`; sort by date, take up to 40 spread evenly (stride, as lsbench `--enrol-from-same`). Per source: `AudioConverter().resampleAudioFile` (FLAC works, the coach does it), Silero ranges via `NotesVoiceDetector`, `NotesSpeech.joined`, then `NotesSpeakerSplitter.embed`. Voiceprint = normalized mean; `selfScoreMedian` = median cosine of the sources against it; `sourceSeconds` summed speech. Fewer than 5 usable sources throws "Dictate a few more times first". Save as `you` with `isUser: true`, overwriting. Exposed on `NotesClient` as `enrolVoiceprint`, `voiceprint() -> Voiceprint?`, `deleteVoiceprint`. Done: after enrolling on this Mac the file has 256 floats of unit norm and `selfScoreMedian ≥ 0.6` (bench: the user's whole turns scored 0.70–0.85).

9. **Settings** (`HexSettings`): `notesSpeakerLabels: Bool` default `true` (degrades to today's output when the model or voiceprint is missing).

10. **UI** (`NotesView.swift`, `NotesFeature.swift`), after a mock-up: render two or three labelled options with `ImageRenderer` for the transcript (a) bold inline label `You: …` per paragraph, (b) label as a small caps line above each turn, (c) a tinted chip per speaker, and let the user pick before any view edit. Then: Transcript tab shows the chosen shape only when `speakerCount > 1`; Edit keeps the `Label: text` prefixes (`edited` parses them). Notes intro settings gain one section "Speakers": the `notesSpeakerLabels` toggle; a row "Your voice: Learned from N dictations on <date>" or "Not learned yet", with "Learn from my dictations" (progress while running) and "Forget" (confirmation; says notes and transcripts are untouched). No per-speaker renaming in this build.

11. **Done-condition for the whole feature.** (a) `cd HexCore && swift test` green with the new test files. (b) Debug build `--notes-harness record <the 18-min Q&A wav>`: `speakers.json` has at most 8 speakers with turns, speaker 1 ("You") has turns, and the transcript's `You:` lines fall in 0:48–2:10 and 14:50–15:12 (the stretches the user confirmed). (c) `tools/notes-crashtest.py` still passes with labels on: a kill -9 mid-chunk resumes with no duplicate chunk and no renumbering of speakers already in `speakers.json`. (d) A solo 2-min session shows no labels and its JSONL still opens in the previous build.

### Risks

- The `0.5` same-speaker threshold is unmeasured; if the Q&A run (11b) yields more than 8 speakers, raise it, and if two voices merge, lower it. A mixed cluster (user over someone else) scored 0.45 and will be labelled "You"; if that shows in use, raise `matchThreshold` to 0.5 (the user's own cluster was 0.61). Both are one-line constants.
- One Cohere call per turn instead of per chunk: more calls on a busy chunk. Diarization is ~0.1 s per chunk (4 s per 18 min); watch the `pending/` backlog in the Q&A run; if it grows, cap turns per chunk at 8 by merging the shortest.
